# Trail Mapper

A phone web app for South Florida nature trails. It finds trail areas near you or near any place you search, draws each area's paths from OpenStreetMap, shows your live position, warns you when you drift off the path, and draws the way back to parking along the trails.

Open it in your phone's browser and use "Add to Home Screen" to install it. Trail lines and the map pieces you viewed are kept on the phone for use without signal.

Trail data © OpenStreetMap contributors (ODbL). Always follow park maps, signs and trail markers.
